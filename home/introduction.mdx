Reader is a hosted API that turns any web page into clean, structured content - markdown, HTML, metadata, and extracted fields - ready to feed to LLMs, agents, and pipelines.

One endpoint. One `x-api-key` header. You point it at a URL, we handle the rest:

- **Rendering** dynamic, JavaScript-heavy sites so you get the page the user sees
- **Bypassing** bot walls automatically. Pick `standard`, `stealth`, or let `auto` decide
- **Extracting** main content and stripping navigation, ads, and boilerplate
- **Converting** to clean markdown optimized for language models
- **Caching** successful scrapes for 24 hours, so repeat requests are free

## How Reader works

Everything flows through a single endpoint: `POST /v1/read`.

The shape of your request determines what Reader does:

| Request | Mode | Response |
|---|---|---|
| Single `url` | **Scrape** | Synchronous - results returned immediately |
| Array of `urls` | **Batch** | Asynchronous - returns a `jobId` to poll or stream |
| `url` with `maxDepth` / `maxPages` | **Crawl** | Asynchronous - discovers links and scrapes each page |

You don't pick the mode. Reader infers it from your input. See [The read primitive](/home/concepts/read-primitive) for the full mental model.

## Why developers pick Reader

- **One primitive, infinite shapes.** No separate endpoints for scrape, batch, crawl. One `read` call handles all three.
- **Handles the modern web.** Dynamic pages render correctly, bot walls get bypassed automatically in `auto` mode, and you never touch the underlying infrastructure.
- **Built for LLMs.** Output is clean markdown by default, with optional HTML and metadata. Main content extraction removes boilerplate so your tokens aren't wasted.
- **Free tier is actually free.** 1,000 credits a month, no card required. Enough to build and ship a real prototype.
- **Self-hostable.** The underlying engine is open source. Host it yourself if you need to. [Learn more →](/self-hosted)
